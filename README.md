## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` validates that `POST.json` names a real X post, then copies it to `out/POST.json`, where the house reads it and scores the post's likes + reposts + quotes. `POST.json` at this repo's root holds the post's address; it is filled in with the real post URL once the post goes live on X.

## Files

- `main.ts` — the entry program (Node 22, standard library only)
- `POST.json` — the X post's address
- `spotlight.png` — the original poster image made for the post
